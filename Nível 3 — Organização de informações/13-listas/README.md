# 13 — Listas

## Sobre o exercício

Organizar informações cotidianas em listas de compras, tarefas e definições.

## Tecnologias

- HTML5
- CSS3

## Estrutura

- `index.html` — página principal
- `assets/css/style.css` — folha de estilos
- `assets/img/favicon.svg` — ícone da página


## Conceitos praticados

Listas não ordenadas `ul`; listas ordenadas `ol`; listas de definição `dl`, `dt` e `dd`; aninhamento de itens.

## Como executar

1. Abra a pasta deste exercício.
2. Abra o arquivo HTML principal em um navegador moderno.
