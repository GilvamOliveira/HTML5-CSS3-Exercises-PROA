# 16 — Elementos Block e Inline

## Sobre o exercício

Comparar elementos que ocupam blocos da página com aqueles que fluem dentro do texto.

## Tecnologias

- HTML5
- CSS3

## Estrutura

- `index.html` — página principal
- `assets/css/style.css` — folha de estilos
- `assets/img/favicon.svg` — ícone da página


## Conceitos praticados

Comportamento padrão de `div`, `p` e títulos; elementos inline como `span`, `strong` e `a`; fluxo do documento.

## Como executar

1. Abra a pasta deste exercício.
2. Abra o arquivo HTML principal em um navegador moderno.
