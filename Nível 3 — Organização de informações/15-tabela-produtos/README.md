# 15 — Tabela de Produtos

## Sobre o exercício

Modelar um catálogo de loja fictícia com imagens, preços, estoque e situação dos produtos.

## Tecnologias

- HTML5
- CSS3

## Estrutura

- `index.html` — página principal
- `assets/css/style.css` — folha de estilos
- `assets/img/favicon.svg` — ícone da página


## Conceitos praticados

Estrutura semântica de tabela com `thead` e `tbody`; células de dados; imagens em tabelas; apresentação de inventário.

## Como executar

1. Abra a pasta deste exercício.
2. Abra o arquivo HTML principal em um navegador moderno.
