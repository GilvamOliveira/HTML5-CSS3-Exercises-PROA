# 20 — Botões

## Sobre o exercício

Criar controles de ação e introduzir uma interação simples acionada por JavaScript.

## Tecnologias

- HTML5
- CSS3

## Estrutura

- `index.html` — página principal
- `assets/css/style.css` — folha de estilos
- `assets/img/favicon.svg` — ícone da página


## Conceitos praticados

Elemento `button`; associação entre ação e interface; evento de clique; mensagem simples em JavaScript.

## Como executar

1. Abra a pasta deste exercício.
2. Abra o arquivo HTML principal em um navegador moderno.
