# 17 — Organização com DIV

## Sobre o exercício

Estruturar uma página com cabeçalho, menu, conteúdo principal, barra lateral e rodapé.

## Tecnologias

- HTML5
- CSS3

## Estrutura

- `index.html` — página principal
- `assets/css/style.css` — folha de estilos
- `assets/img/favicon.svg` — ícone da página


## Conceitos praticados

Agrupamento com `div`; classes CSS; Flexbox com `display: flex`; proporções com `flex`; pseudo-classe `:hover`.

## Como executar

1. Abra a pasta deste exercício.
2. Abra o arquivo HTML principal em um navegador moderno.
