# 28 — Backgrounds

## Sobre o exercício

Experimentar cores, imagens, posicionamento, repetição e gradientes como fundo de seções.

## Tecnologias

- HTML5
- CSS3

## Estrutura

- `index.html` — página principal
- `assets/css/style.css` — folha de estilos
- `assets/img/favicon.svg` — ícone da página


## Conceitos praticados

`background-color`; `background-image`; `background-size`; `background-position`; `background-repeat`; gradientes e sobreposição.

## Como executar

1. Abra a pasta deste exercício.
2. Abra o arquivo HTML principal em um navegador moderno.
