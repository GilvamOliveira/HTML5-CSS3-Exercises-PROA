# 29 — Cards

## Sobre o exercício

Construir cartões informativos para cursos, usando espaçamento, bordas, sombras e botões.

## Tecnologias

- HTML5
- CSS3

## Estrutura

- `index.html` — página principal
- `assets/css/style.css` — folha de estilos
- `assets/img/favicon.svg` — ícone da página


## Conceitos praticados

Componente `.card`; Flexbox com quebra de linha; `margin` e `padding`; bordas arredondadas; `box-shadow`; estilização de botões.

## Como executar

1. Abra a pasta deste exercício.
2. Abra o arquivo HTML principal em um navegador moderno.
