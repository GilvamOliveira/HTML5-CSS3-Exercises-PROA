# 24 — Sintaxe CSS

## Sobre o exercício

Praticar a estrutura de regras CSS e aplicar propriedades visuais a títulos e parágrafos.

## Tecnologias

- HTML5
- CSS3

## Estrutura

- `index.html` — página principal
- `assets/css/style.css` — folha de estilos
- `assets/img/favicon.svg` — ícone da página


## Conceitos praticados

Sintaxe `seletor { propriedade: valor; }`; seletores de elemento; cor; tipografia; espaçamento; bordas arredondadas.

## Como executar

1. Abra a pasta deste exercício.
2. Abra o arquivo HTML principal em um navegador moderno.
