# 26 — Caça aos Erros de CSS

## Sobre o exercício

Identificar erros comuns de sintaxe e comparar uma folha de estilos incorreta com sua versão corrigida.

## Tecnologias

- HTML5
- CSS3

## Estrutura

- `index.html` — página principal
- `assets/css/style.css` — estilos do exercício
- `assets/css/style-com-erros.css` — versão com os seis erros
- `assets/css/style-corrigido.css` — versão corrigida
- `assets/img/favicon.svg` — ícone da página


## Conceitos praticados

Pontos e vírgulas; chaves; nomes de propriedades; valores válidos; depuração visual e leitura de regras CSS.

## Como executar

1. Abra a pasta deste exercício.
2. Abra o arquivo HTML principal em um navegador moderno.
