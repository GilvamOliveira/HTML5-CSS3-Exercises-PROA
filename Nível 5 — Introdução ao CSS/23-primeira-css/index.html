Exercício 23

Minha primeira estilização com CSS

Comparar as três formas de aplicar CSS em uma página: externo, interno e inline.

Bem-vindo(a) à minha página!

Este parágrafo está estilizado usando um arquivo CSS externo, conectado por meio da tag <link> dentro do <head>.

Este título usa CSS interno

Este parágrafo usa CSS inline (estilo escrito diretamente no atributo style do elemento).

Diferenças: o CSS externo (style.css) é reutilizável em várias páginas e mantém o código organizado; o CSS interno (dentro de <style>) vale só para a página atual; e o CSS inline vale só para o elemento onde foi escrito, tendo a maior prioridade entre os três, porém deve ser evitado em projetos maiores por dificultar a manutenção.
