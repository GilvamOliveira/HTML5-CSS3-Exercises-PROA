# 23 — Primeira Estilização com CSS

## Sobre o exercício

Comparar as três formas de aplicar CSS em uma página: externo, interno e inline.

## Tecnologias

- HTML5
- CSS3

## Estrutura

- `index.html` — página principal
- `assets/css/style.css` — folha de estilos
- `assets/img/favicon.svg` — ícone da página


## Conceitos praticados

CSS externo com `link`; CSS interno com `style`; CSS inline; seletores de elemento; propriedades de cor, tipografia e alinhamento.

## Como executar

1. Abra a pasta deste exercício.
2. Abra o arquivo HTML principal em um navegador moderno.
