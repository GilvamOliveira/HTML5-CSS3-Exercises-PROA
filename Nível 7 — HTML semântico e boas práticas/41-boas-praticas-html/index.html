Exercício 41

Aplicando boas práticas HTML

Revise um conjunto de boas práticas de estrutura, acessibilidade e organização que devem acompanhar todo documento HTML.

Checklist essencial

  • Declare <!DOCTYPE html> na primeira linha.
  • Informe o idioma com <html lang="pt-BR">.
  • Use <meta charset="UTF-8"> para acentos e símbolos.
  • Inclua viewport para telas móveis.
  • Escreva um title único e descritivo.
  • Mantenha a hierarquia de títulos: h1, depois h2, e assim por diante.
  • Use elementos semânticos antes de recorrer a div.
  • Forneça alt para imagens informativas.
  • Associe cada campo de formulário a um label.
  • Prefira textos de link descritivos, como “baixar o edital”, em vez de “clique aqui”.

Compare

Boa prática

<html lang="pt-BR">
<head>
    <meta charset="UTF-8">
    <title>Contato — Loja Exemplo</title>
</head>

<label for="email">E-mail</label>
<input id="email" type="email">

<img src="logo.svg" alt="Logotipo da Loja Exemplo">

Evite

<html>
<head>
    <title>Página</title>
</head>

<p>E-mail</p>
<input type="email">

<img src="logo.svg">

Validação

Depois de escrever o HTML, verifique se as tags estão fechadas, se os IDs são únicos e se os caminhos de arquivos estão corretos. Ferramentas de validação ajudam a encontrar erros que o navegador costuma corrigir silenciosamente.

Boas práticas não são regras decorativas: elas melhoram a experiência de quem usa e de quem mantém o projeto.
