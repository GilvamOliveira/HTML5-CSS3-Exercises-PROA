# 41 — Aplicando Boas Práticas HTML

## Sobre o exercício

Revise um conjunto de boas práticas de estrutura, acessibilidade e organização que devem acompanhar todo documento HTML.

## Tecnologias

- HTML5
- CSS3

## Estrutura

- `index.html` — página principal
- `assets/css/style.css` — folha de estilos
- `assets/img/favicon.svg` — ícone da página


## Conceitos praticados

`DOCTYPE`; atributo `lang`; `charset`; `title`; hierarquia de títulos; texto alternativo; rótulos de formulário; links descritivos; código válido e organizado.

## Como executar

1. Abra a pasta deste exercício.
2. Abra o arquivo `index.html` em um navegador moderno.
