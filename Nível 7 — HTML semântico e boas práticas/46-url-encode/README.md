# 46 — Explorando URL Encode

## Sobre o exercício

Entenda como espaços, acentos e caracteres especiais são codificados em endereços e parâmetros de formulário.

## Tecnologias

- HTML5
- CSS3

## Estrutura

- `index.html` — página principal
- `assets/css/style.css` — folha de estilos
- `assets/img/favicon.svg` — ícone da página

## Conceitos praticados

URLs e query strings; codificação percentual; `%20`; caracteres reservados; codificação de acentos em UTF-8; formulários com método `GET`.

## Como executar

1. Abra a pasta deste exercício.
2. Abra o arquivo `index.html` em um navegador moderno.
