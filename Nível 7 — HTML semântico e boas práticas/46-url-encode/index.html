Explorando URL Encode

Navegadores codificam automaticamente caracteres especiais para que a URL continue válida.

Tabela de codificação

Caractere Codificado Uso comum
espaço%20Separa palavras em uma busca
#%23Fragmento da URL
&%26Separa parâmetros
?%3FInicia a query string
=%3DAtribui valor ao parâmetro
/%2FSepara caminhos
ç%C3%A7Letra acentuada em UTF-8
ã%C3%A3Letra acentuada em UTF-8

Exemplos de URL

https://example.com/busca?q=HTML%20e%20CSS

https://example.com/pesquisa?termo=programa%C3%A7%C3%A3o

Na segunda URL, programa%C3%A7%C3%A3o representa a palavra “programação”.

Teste com um formulário

O método GET envia os dados na própria URL. Ao enviar, observe a barra de endereços.
