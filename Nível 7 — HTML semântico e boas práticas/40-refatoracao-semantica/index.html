Exercício 40

Refatoração semântica

A mesma interface pode ser construída com divs ou com elementos semânticos. O resultado visual é parecido, mas a qualidade do código muda.

Versão refatorada

Esta página usa header, nav, main, article, aside e footer. Cada elemento comunica sua função.

Depois: semântico

<header>...</header>
<nav>...</nav>
<main>
    <article>...</article>
    <aside>...</aside>
</main>
<footer>...</footer>

Mais acessível, legível e fácil de manter.

Antes: apenas divs

<div class="topo">...</div>
<div class="menu">...</div>
<div class="conteudo">
    <div class="post">...</div>
    <div class="lateral">...</div>
</div>
<div class="rodape">...</div>

Funciona visualmente, mas não descreve o conteúdo.
