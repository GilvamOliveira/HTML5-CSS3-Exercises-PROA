# 40 — Refatoração semântica

## Sobre o exercício

Compare uma página construída apenas com divs com a mesma página refatorada usando elementos semânticos.

## Tecnologias

- HTML5
- CSS3

## Estrutura

- `index.html` — página principal
- `assets/css/style.css` — folha de estilos
- `assets/img/favicon.svg` — ícone da página
- `antes.html` — versão sem semântica, usada para comparação

## Conceitos praticados

Refatoração de marcação; substituição de `div` por elementos com significado; `header`, `nav`, `main`, `article`, `aside` e `footer`; separação entre estrutura e aparência.

## Como executar

1. Abra a pasta deste exercício.
2. Abra o arquivo `index.html` em um navegador moderno.
