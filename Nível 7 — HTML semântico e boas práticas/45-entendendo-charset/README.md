# 45 — Entendendo Charset

## Sobre o exercício

Compreenda por que a declaração charset é essencial para exibir acentos e símbolos corretamente.

## Tecnologias

- HTML5
- CSS3

## Estrutura

- `index.html` — página principal
- `assets/css/style.css` — folha de estilos
- `assets/img/favicon.svg` — ícone da página


## Conceitos praticados

Codificação de caracteres; `meta charset`; UTF-8; acentos e cedilha; problemas de codificação; declaração no início do `head`.

## Como executar

1. Abra a pasta deste exercício.
2. Abra o arquivo `index.html` em um navegador moderno.
