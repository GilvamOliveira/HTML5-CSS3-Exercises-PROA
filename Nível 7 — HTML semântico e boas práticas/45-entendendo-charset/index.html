Exercício 45

Entendendo Charset

Compreenda por que a declaração charset é essencial para exibir acentos e símbolos corretamente.

Declaração correta

<head>
    <meta charset="UTF-8">
    <title>Página com acentos</title>
</head>

UTF-8 é a codificação recomendada para a web. Ela representa praticamente todos os caracteres usados no mundo.

Texto com acentos

Ação, coração, pão, maçã, você, avô, língua, programação e informação.

Se o arquivo for salvo em UTF-8 e a página declarar UTF-8, esses caracteres são exibidos corretamente.

Resumo

  • UTF-8 evita a maior parte dos problemas.
  • O editor de código também precisa salvar em UTF-8.
  • Bancos de dados e servidores devem usar a mesma codificação.
