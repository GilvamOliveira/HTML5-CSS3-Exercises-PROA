Por que escapar?

Se escrevermos <strong> diretamente no conteúdo, o navegador interpreta a tag. Para mostrar o texto literal, usamos &lt;strong&gt;.

<p>Use &lt;strong&gt; para destacar uma palavra.</p>

Resultado: <strong> aparece como texto em vez de virar um elemento.
