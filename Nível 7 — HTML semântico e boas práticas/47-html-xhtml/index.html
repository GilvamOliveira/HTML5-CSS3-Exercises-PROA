Exercício 47

HTML versus XHTML

HTML5 é tolerante; XHTML exige uma sintaxe mais rígida, baseada em XML.

Comparação

Aspecto HTML5 XHTML
DOCTYPE <!DOCTYPE html> Declaração XML + DTD
Tags vazias Aceita <br> Exige <br />
Maiúsculas Tags podem ser maiúsculas ou minúsculas Diferencia maiúsculas de minúsculas
Atributos Aspas são recomendadas Aspas são obrigatórias
Erros O navegador tenta corrigir A página pode falhar

Exemplos lado a lado

HTML5

<!DOCTYPE html>
<html lang="pt-BR">
<head>
    <meta charset="UTF-8">
    <title>Exemplo</title>
</head>
<body>
    <img src="foto.jpg" alt="Foto">
    <br>
</body>
</html>

XHTML

<!DOCTYPE html PUBLIC
  "-//W3C//DTD XHTML 1.0 Strict//EN"
  "http://www.w3.org/TR/xhtml1/DTD/xhtml1-strict.dtd">
<html xmlns="http://www.w3.org/1999/xhtml" lang="pt-BR">
<head>
    <meta http-equiv="Content-Type"
          content="text/html; charset=UTF-8" />
    <title>Exemplo</title>
</head>
<body>
    <img src="foto.jpg" alt="Foto" />
    <br />
</body>
</html>

Qual usar?

Para projetos novos na web, HTML5 é o padrão recomendado. XHTML ainda aparece em sistemas antigos e em contextos que exigem XML. O importante é conhecer as regras da linguagem escolhida e manter a consistência.
