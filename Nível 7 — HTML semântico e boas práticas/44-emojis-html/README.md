# 44 — Emojis em HTML

## Sobre o exercício

Adicione emojis a cards e textos usando caracteres Unicode, com atenção à codificação UTF-8 e ao contexto.

## Tecnologias

- HTML5
- CSS3

## Estrutura

- `index.html` — página principal
- `assets/css/style.css` — folha de estilos
- `assets/img/favicon.svg` — ícone da página

## Conceitos praticados

Emojis como caracteres Unicode; codificação UTF-8; uso moderado em interfaces; leitura por tecnologias assistivas; contraste com texto.

## Como executar

1. Abra a pasta deste exercício.
2. Abra o arquivo `index.html` em um navegador moderno.
