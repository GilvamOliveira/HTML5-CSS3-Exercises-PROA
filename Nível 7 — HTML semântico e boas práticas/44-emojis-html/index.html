Cuidados

  • Use emojis com moderação em interfaces profissionais.
  • Não substitua informações importantes apenas por emojis.
  • Marque emojis decorativos com aria-hidden="true" quando houver texto equivalente.
  • Teste em diferentes sistemas: o desenho pode variar.
