# 39 — HTML Semântico

## Sobre o exercício

Estruture um artigo de blog com elementos semânticos que descrevem claramente o papel de cada área da página.

## Tecnologias

- HTML5
- CSS3

## Estrutura

- `index.html` — página principal
- `assets/css/style.css` — folha de estilos
- `assets/img/favicon.svg` — ícone da página


## Conceitos praticados

Elementos `header`, `nav`, `main`, `article`, `section`, `aside` e `footer`; hierarquia de títulos; landmarks; legibilidade do código e acessibilidade.

## Como executar

1. Abra a pasta deste exercício.
2. Abra o arquivo `index.html` em um navegador moderno.
