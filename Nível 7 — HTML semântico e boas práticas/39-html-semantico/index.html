Por que usar HTML semântico?

Publicado por Equipe PROA • Leitura de 5 minutos

O que é HTML semântico?

HTML semântico é o uso de elementos que descrevem o significado do conteúdo, e não apenas sua aparência. Em vez de construir tudo com <div>, usamos tags como <header>, <nav>, <main> e <article>.

Benefícios principais

  • Acessibilidade: leitores de tela identificam as regiões da página.
  • SEO: mecanismos de busca compreendem melhor a estrutura do conteúdo.
  • Manutenção: o código fica mais fácil de ler e alterar.
  • Consistência: a equipe compartilha os mesmos significados.

Um exemplo de estrutura

<header>Cabeçalho</header>
<nav>Menu de navegação</nav>
<main>
    <article>Conteúdo principal</article>
    <aside>Conteúdo complementar</aside>
</main>
<footer>Rodapé</footer>

Conclusão: escolher a tag certa torna a página mais compreensível para pessoas, navegadores e tecnologias assistivas.

Sobre este exercício

Observe que cada região possui uma função clara. O menu está em nav, o texto principal em article e as informações extras em aside.

Checklist

  • Um único main por página.
  • Títulos em ordem hierárquica.
  • Links com texto descritivo.
  • Landmarks identificáveis.
