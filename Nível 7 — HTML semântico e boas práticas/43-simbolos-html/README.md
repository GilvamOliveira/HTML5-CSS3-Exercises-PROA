# 43 — Símbolos HTML

## Sobre o exercício

Use símbolos matemáticos, setas, moedas e naipes para enriquecer o conteúdo de uma página.

## Tecnologias

- HTML5
- CSS3

## Estrutura

- `index.html` — página principal
- `assets/css/style.css` — folha de estilos
- `assets/img/favicon.svg` — ícone da página

## Conceitos praticados

Símbolos por entidade e por Unicode; setas; operadores matemáticos; moedas; naipes; consistência tipográfica.

## Como executar

1. Abra a pasta deste exercício.
2. Abra o arquivo `index.html` em um navegador moderno.
