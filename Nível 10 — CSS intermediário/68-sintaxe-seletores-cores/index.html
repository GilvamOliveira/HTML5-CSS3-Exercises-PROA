Exercício 68

Sintaxe, seletores, cores e comentários

Pratique a estrutura de uma regra CSS, diferentes seletores, formatos de cor e comentários.

Sintaxe básica

seletor {
    propriedade: valor;
    outra-propriedade: outro-valor;
}

O seletor escolhe os elementos. Cada declaração possui uma propriedade e um valor, separados por dois-pontos e finalizados com ponto e vírgula.

Seletores na prática

Parágrafo comum, estilizado pelo seletor de elemento.

Parágrafo com a classe .destaque.

Parágrafo com o ID #unico.

Parágrafo com o atributo data-tipo="aviso".

Passe o mouse para ver a pseudo-classe :hover

Cores

#0b5ed7
rgb(11, 94, 215)
hsl(215, 90%, 44%)
navy
color: #0b5ed7;
color: rgb(11, 94, 215);
color: hsl(215, 90%, 44%);
color: navy;

Todos os exemplos representam cores válidas. Escolha o formato mais legível para o contexto.

Comentários

/* Comentário de uma linha */

p {
    color: #333333; /* comentário no fim da linha */
}

/*
    Comentário de várias linhas
    para explicar um bloco maior.
*/

Comentários não aparecem na página e ajudam a documentar decisões de estilo.
