# 69 — Background, Border, Margin e Padding

## Sobre o exercício

Explore fundos, bordas, margens e preenchimento para construir e compreender o modelo de caixa do CSS.

## Tecnologias

- HTML5
- CSS3

## Estrutura

- `index.html` — página principal
- `assets/css/style.css` — folha de estilos
- `assets/img/favicon.svg` — ícone da página
- `assets/img/pattern.svg` — padrão usado como fundo repetido
- `assets/img/paisagem.svg` — imagem usada como fundo de capa

## Conceitos praticados

Box model; `background-color`, `background-image`, `background-size` e `background-repeat`; `border`; `border-radius`; `margin`; `padding`; `box-sizing`.

## Como executar

1. Abra a pasta deste exercício.
2. Abra o arquivo `index.html` em um navegador moderno.
