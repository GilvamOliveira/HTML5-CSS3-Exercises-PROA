Três maneiras de aplicar CSS

O mesmo estilo pode ser declarado de formas diferentes. Cada uma tem um impacto na organização e na manutenção do projeto.

CSS externo

Arquivo separado

É a forma recomendada para projetos reais: o CSS fica em assets/css/style.css e é vinculado com <link rel="stylesheet">.

Ver prioridade
CSS interno

Bloco style no head

As regras ficam dentro de <style>, no head. É útil para uma página isolada ou para estilos críticos, mas não reutiliza estilos entre páginas.

CSS inline

Atributo style no elemento

O estilo inline afeta apenas um elemento e tem prioridade sobre regras externas de mesma importância. Use com moderação, pois mistura conteúdo e apresentação.

Ordem de prioridade

Forma Onde fica Reutilização Prioridade
ExternoArquivo .cssAltaDefinida pela cascata
InternoTag styleBaixaDefinida pela cascata
InlineAtributo styleMuito baixaAlta

A prioridade real considera também a especificidade do seletor e a ordem em que as regras aparecem. Evite !important como solução padrão.
