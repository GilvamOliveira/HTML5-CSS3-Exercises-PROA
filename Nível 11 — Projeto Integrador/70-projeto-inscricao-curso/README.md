# 70 — Página completa de inscrição em curso

## Sobre o exercício

Projeto integrador: construa uma página completa de apresentação e inscrição em um curso, reunindo HTML semântico, CSS, formulários e JavaScript.

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Estrutura

- `index.html` — página principal
- `assets/css/style.css` — folha de estilos
- `assets/img/favicon.svg` — ícone da página
- `assets/img/logo.svg` — logotipo do projeto
- `assets/img/banner.svg` — ilustração do cabeçalho
- `script.js` — feedback do formulário

## Conceitos praticados

Estrutura completa de página; HTML semântico; CSS externo; layout responsivo com Grid e Flexbox; formulários e validação; JavaScript para feedback; organização de assets.

## Como executar

1. Abra a pasta deste exercício.
2. Abra o arquivo `index.html` em um navegador moderno.
