# 51 — Tipos básicos de input

## Sobre o exercício

Pratique os principais tipos de input e observe como cada um adapta teclado, validação e interface.

## Tecnologias

- HTML5
- CSS3

## Estrutura

- `index.html` — página principal
- `assets/css/style.css` — folha de estilos
- `assets/img/favicon.svg` — ícone da página

## Conceitos praticados

`type="text"`, `email`, `password`, `tel`, `url`, `search`, `number` e `date`; teclados móveis; validação nativa; atributos `name` e `autocomplete`.

## Como executar

1. Abra a pasta deste exercício.
2. Abra o arquivo `index.html` em um navegador moderno.
