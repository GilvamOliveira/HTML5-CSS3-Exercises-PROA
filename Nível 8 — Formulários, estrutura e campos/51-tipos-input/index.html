Tipos básicos de input

Pratique os principais tipos de input e observe como cada um adapta teclado, validação e interface.

Formulário de perfil

Por que o tipo importa?

  • Em celulares, o teclado se adapta ao tipo de dado.
  • O navegador pode validar formato de e-mail, URL e número.
  • Leitores de tela anunciam o campo com mais contexto.
  • O preenchimento automático funciona melhor com autocomplete.
