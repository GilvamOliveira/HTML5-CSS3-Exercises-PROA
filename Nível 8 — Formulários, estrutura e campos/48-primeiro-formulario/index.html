Exercício 48

Primeiro formulário

Formulários coletam dados do usuário. Comece com uma estrutura simples, acessível e fácil de validar.

Fale conosco

Os campos abaixo usam rótulos associados, validação nativa e nomes que identificam cada dado enviado.

Usaremos este endereço apenas para responder à mensagem.

Anatomia do formulário

<form action="#" method="post">
    <label for="email">E-mail</label>
    <input id="email" name="email" type="email" required>

    <button type="submit">Enviar</button>
</form>

O for do rótulo deve apontar para o id do campo. O atributo name é o nome do dado enviado ao servidor.
