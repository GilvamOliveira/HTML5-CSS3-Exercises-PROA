Exercício 55

Textarea

Crie áreas de texto multilinha com controle de tamanho, limite de caracteres e redimensionamento.

Comentário sobre o curso

Máximo de 300 caracteres. O navegador impede o excesso.

Diferença para input

Enquanto <input type="text"> é uma linha, <textarea> permite várias linhas. O conteúdo inicial fica entre as tags de abertura e fechamento.

<textarea name="mensagem" rows="5" cols="40">
Texto inicial
</textarea>

Use CSS com resize: vertical para permitir que o usuário aumente apenas a altura.
