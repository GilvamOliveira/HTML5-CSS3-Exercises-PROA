# 55 — Textarea

## Sobre o exercício

Crie áreas de texto multilinha com controle de tamanho, limite de caracteres e redimensionamento.

## Tecnologias

- HTML5
- CSS3

## Estrutura

- `index.html` — página principal
- `assets/css/style.css` — folha de estilos
- `assets/img/favicon.svg` — ícone da página


## Conceitos praticados

`textarea`; `rows` e `cols`; `maxlength`; `placeholder`; `readonly` e `disabled`; redimensionamento com CSS; acessibilidade.

## Como executar

1. Abra a pasta deste exercício.
2. Abra o arquivo `index.html` em um navegador moderno.
