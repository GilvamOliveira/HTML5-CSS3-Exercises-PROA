# 52 — Radio Buttons

## Sobre o exercício

Use botões de rádio para permitir uma única escolha dentro de um grupo de opções relacionadas.

## Tecnologias

- HTML5
- CSS3

## Estrutura

- `index.html` — página principal
- `assets/css/style.css` — folha de estilos
- `assets/img/favicon.svg` — ícone da página


## Conceitos praticados

`input type="radio"`; agrupamento pelo atributo `name`; `value`; `checked`; `fieldset` e `legend`; rótulos clicáveis; escolha única.

## Como executar

1. Abra a pasta deste exercício.
2. Abra o arquivo `index.html` em um navegador moderno.
