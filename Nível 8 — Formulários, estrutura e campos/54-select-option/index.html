Select e Option

Listas suspensas economizam espaço quando há muitas opções. O elemento optgroup agrupa alternativas relacionadas.

Escolha seu curso

Segure Ctrl (Windows) ou Command (macOS) para selecionar mais de uma opção.

Atributos úteis

  • selected define a opção inicial.
  • disabled impede a seleção de uma opção.
  • multiple permite várias escolhas.
  • size exibe mais de uma linha por vez.
  • optgroup agrupa opções com um rótulo.
<select name="curso">
    <optgroup label="Desenvolvimento web">
        <option value="html">HTML5 e CSS3</option>
        <option value="js">JavaScript</option>
    </optgroup>
</select>
