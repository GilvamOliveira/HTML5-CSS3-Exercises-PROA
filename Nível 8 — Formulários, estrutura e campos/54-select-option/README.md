# 54 — Select e Option

## Sobre o exercício

Crie listas suspensas com select, option, optgroup e seleção múltipla para organizar muitas opções.

## Tecnologias

- HTML5
- CSS3

## Estrutura

- `index.html` — página principal
- `assets/css/style.css` — folha de estilos
- `assets/img/favicon.svg` — ícone da página


## Conceitos praticados

`select`; `option`; `optgroup`; `selected`; `multiple`; `size`; `disabled`; organização de listas extensas.

## Como executar

1. Abra a pasta deste exercício.
2. Abra o arquivo `index.html` em um navegador moderno.
