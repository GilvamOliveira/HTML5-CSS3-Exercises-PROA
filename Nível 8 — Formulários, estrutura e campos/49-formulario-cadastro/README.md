# 49 — Formulário de cadastro

## Sobre o exercício

Monte um formulário de cadastro com dados pessoais, senha, data de nascimento, seleção de gênero e aceite dos termos.

## Tecnologias

- HTML5
- CSS3

## Estrutura

- `index.html` — página principal
- `assets/css/style.css` — folha de estilos
- `assets/img/favicon.svg` — ícone da página

## Conceitos praticados

Formulário completo de cadastro; tipos de `input`; agrupamento de opções; `autocomplete`; validação nativa; `required`; organização em grade.

## Como executar

1. Abra a pasta deste exercício.
2. Abra o arquivo `index.html` em um navegador moderno.
