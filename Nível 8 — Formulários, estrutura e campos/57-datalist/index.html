Exercício 57

Datalist

Ofereça sugestões de preenchimento com datalist sem impedir que o usuário digite um valor próprio.

Escolha uma tecnologia

Você pode digitar uma tecnologia que não esteja na lista.

Select ou datalist?

Use select quando o usuário deve escolher apenas uma opção válida da lista. Use datalist quando as sugestões são apenas uma ajuda e o valor digitado pode ser diferente.

<input list="sugestoes" name="tecnologia">
<datalist id="sugestoes">
    <option value="HTML5">
    <option value="CSS3">
</datalist>
