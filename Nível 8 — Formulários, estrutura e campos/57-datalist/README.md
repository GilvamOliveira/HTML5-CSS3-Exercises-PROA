# 57 — Datalist

## Sobre o exercício

Ofereça sugestões de preenchimento com datalist sem impedir que o usuário digite um valor próprio.

## Tecnologias

- HTML5
- CSS3

## Estrutura

- `index.html` — página principal
- `assets/css/style.css` — folha de estilos
- `assets/img/favicon.svg` — ícone da página

## Conceitos praticados

`datalist`; associação com `input` pelo atributo `list`; `option` como sugestão; diferença para `select`; liberdade de digitação.

## Como executar

1. Abra a pasta deste exercício.
2. Abra o arquivo `index.html` em um navegador moderno.
