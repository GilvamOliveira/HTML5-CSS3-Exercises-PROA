Form Attributes

Os atributos do formulário definem para onde, como e com qual formato os dados serão enviados.

Principais atributos

Atributo Função Exemplo
action Endereço que recebe os dados. action="/cadastro"
method Método HTTP usado no envio. method="post"
target Onde abrir a resposta. target="_blank"
enctype Formato dos dados enviados. enctype="multipart/form-data"
autocomplete Permite sugestões do navegador. autocomplete="on"
novalidate Desativa a validação nativa. novalidate

Formulário de exemplo

GET e POST

GET envia os dados na URL e é indicado para buscas e filtros. POST envia os dados no corpo da requisição e é mais adequado para cadastros, login e informações sensíveis.

Nenhum dado é processado neste exemplo: o formulário usa action="#" apenas para demonstração.
