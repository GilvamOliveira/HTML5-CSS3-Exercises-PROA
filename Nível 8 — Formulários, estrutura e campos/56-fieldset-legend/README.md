# 56 — Fieldset e Legend

## Sobre o exercício

Agrupe campos relacionados com fieldset e legend para tornar formulários longos mais compreensíveis.

## Tecnologias

- HTML5
- CSS3

## Estrutura

- `index.html` — página principal
- `assets/css/style.css` — folha de estilos
- `assets/img/favicon.svg` — ícone da página


## Conceitos praticados

`fieldset`; `legend`; agrupamento lógico; leitura por tecnologias assistivas; organização de formulários extensos.

## Como executar

1. Abra a pasta deste exercício.
2. Abra o arquivo `index.html` em um navegador moderno.
