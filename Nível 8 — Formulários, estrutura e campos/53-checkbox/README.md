# 53 — Checkbox

## Sobre o exercício

Use caixas de seleção para permitir múltiplas escolhas independentes em um formulário.

## Tecnologias

- HTML5
- CSS3

## Estrutura

- `index.html` — página principal
- `assets/css/style.css` — folha de estilos
- `assets/img/favicon.svg` — ícone da página


## Conceitos praticados

`input type="checkbox"`; múltiplas seleções; `value`; `checked`; `disabled`; rótulos clicáveis; diferença entre checkbox e radio.

## Como executar

1. Abra a pasta deste exercício.
2. Abra o arquivo `index.html` em um navegador moderno.
