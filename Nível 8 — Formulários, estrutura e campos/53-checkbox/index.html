Checkbox x radio

Use checkbox para escolhas independentes e múltiplas. Use radio quando apenas uma opção puder ser escolhida.

Para que vários checkboxes enviem valores diferentes, todos podem compartilhar o mesmo name, mas cada um deve ter seu próprio value.
