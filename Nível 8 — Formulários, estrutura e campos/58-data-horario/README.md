# 58 — Inputs de data e horário

## Sobre o exercício

Use campos nativos de data, hora, data e hora local, mês e semana para coletar informações temporais.

## Tecnologias

- HTML5
- CSS3

## Estrutura

- `index.html` — página principal
- `assets/css/style.css` — folha de estilos
- `assets/img/favicon.svg` — ícone da página

## Conceitos praticados

`type="date"`; `type="time"`; `type="datetime-local"`; `type="month"`; `type="week"`; formato de valor; seletores nativos.

## Como executar

1. Abra a pasta deste exercício.
2. Abra o arquivo `index.html` em um navegador moderno.
