# 31 — Laboratório de Botões

## Sobre o exercício

Explore os tipos, estados e variações visuais de botões em HTML e CSS.

## Tecnologias

- HTML5
- CSS3

## Estrutura

- `index.html` — página principal
- `assets/css/style.css` — folha de estilos
- `assets/img/favicon.svg` — ícone da página


## Conceitos praticados

Elemento `button`; atributo `type`; estados `:hover`, `:focus-visible`, `:active` e `:disabled`; botões com aparência de link; acessibilidade e área de clique.

## Como executar

1. Abra a pasta deste exercício.
2. Abra o arquivo `index.html` em um navegador moderno.
