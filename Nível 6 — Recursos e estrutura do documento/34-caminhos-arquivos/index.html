Exercício 34

Organizando caminhos de arquivos

Um mesmo site pode ter páginas em pastas diferentes. Os caminhos relativos indicam ao navegador onde cada arquivo está.

Início Sobre Contato

Mapa de caminhos

index.html → pages/sobre.html

Desce para a pasta pages.

pages/sobre.html → ../index.html

Sobe um nível para voltar à raiz.

index.html → assets/img/logo.svg

Entra na pasta de recursos do projeto.

Recursos compartilhados

O logotipo está em assets/img/logo.svg e é referenciado a partir da raiz.

Nas páginas internas, o mesmo arquivo é acessado com ../assets/img/logo.svg.

Pratique

Abra as páginas Sobre e Contato pelo menu e observe a barra de endereço do navegador. Depois, use o link Início para retornar.
