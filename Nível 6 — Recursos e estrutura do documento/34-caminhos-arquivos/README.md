# 34 — Organizando Caminhos de Arquivos

## Sobre o exercício

Navegue entre páginas e recursos usando caminhos relativos, entendendo quando subir ou descer diretórios.

## Tecnologias

- HTML5
- CSS3

## Estrutura

- `index.html` — página principal
- `assets/css/style.css` — folha de estilos
- `assets/img/favicon.svg` — ícone da página
- `pages/sobre.html` — página interna
- `pages/contato.html` — página interna
- `assets/img/logo.svg` — logotipo usado nas páginas


## Conceitos praticados

Caminhos relativos e absolutos; referências com `./`, `../` e nome direto; organização de páginas em subpastas; vínculo entre HTML, CSS, imagens e páginas internas.

## Como executar

1. Abra a pasta deste exercício.
2. Abra o arquivo `index.html` em um navegador moderno.
