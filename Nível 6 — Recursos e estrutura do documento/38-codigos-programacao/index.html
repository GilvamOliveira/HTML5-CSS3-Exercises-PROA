Exercício 38

Página para códigos de programação

Uma documentação técnica precisa exibir código com clareza, preservando espaços e destacando comandos.

Código em bloco

Use <pre> para manter a formatação e <code> para indicar que o conteúdo é código.

function saudar(nome) {
    const mensagem = "Olá, " + nome + "!";
    return mensagem;
}

console.log(saudar("Aluno"));

HTML de exemplo

Os sinais de menor e maior precisam ser escapados com &lt; e &gt;.

<article class="card">
    <h2>Título</h2>
    <p>Conteúdo do cartão.</p>
</article>

Elementos semânticos para tecnologia

  • <code> — trecho de código.
  • <kbd> — tecla ou comando: pressione Ctrl + S.
  • <samp> — saída de programa: Arquivo salvo com sucesso.
  • <var> — variável: total = preco × quantidade.
