# 38 — Página para códigos de programação

## Sobre o exercício

Apresente trechos de código em uma página usando pre, code, kbd, samp e var com uma formatação legível.

## Tecnologias

- HTML5
- CSS3

## Estrutura

- `index.html` — página principal
- `assets/css/style.css` — folha de estilos
- `assets/img/favicon.svg` — ícone da página

## Conceitos praticados

Elementos `pre` e `code`; preservação de espaços; escape de caracteres com entidades HTML; `kbd`, `samp` e `var`; estilização de blocos de código.

## Como executar

1. Abra a pasta deste exercício.
2. Abra o arquivo `index.html` em um navegador moderno.
