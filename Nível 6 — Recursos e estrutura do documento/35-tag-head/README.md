# 35 — Explorando a Tag HEAD

## Sobre o exercício

Conheça os metadados que ficam dentro de head e entenda como eles descrevem a página para navegadores e mecanismos de busca.

## Tecnologias

- HTML5
- CSS3

## Estrutura

- `index.html` — página principal
- `assets/css/style.css` — folha de estilos
- `assets/img/favicon.svg` — ícone da página


## Conceitos praticados

Elemento `head`; `meta charset`; `viewport`; `description`; `keywords`; `author`; `robots`; `theme-color`; Open Graph; `title`; `link` e `script`.

## Como executar

1. Abra a pasta deste exercício.
2. Abra o arquivo `index.html` em um navegador moderno.
