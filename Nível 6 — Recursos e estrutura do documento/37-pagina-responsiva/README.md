# 37 — Sua primeira página responsiva

## Sobre o exercício

Construa uma página que se adapta a celulares, tablets e desktops usando unidades flexíveis, Grid e media queries.

## Tecnologias

- HTML5
- CSS3

## Estrutura

- `index.html` — página principal
- `assets/css/style.css` — folha de estilos
- `assets/img/favicon.svg` — ícone da página
- `assets/img/banner.svg` — ilustração do cabeçalho

## Conceitos praticados

`viewport`; unidades relativas; `clamp()`; Grid com `auto-fit`; imagens flexíveis; media queries; abordagem mobile-first.

## Como executar

1. Abra a pasta deste exercício.
2. Abra o arquivo `index.html` em um navegador moderno.
