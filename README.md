# 30 Exercícios Práticos — HTML5 + CSS3

Coleção progressiva de exercícios de front-end desenvolvida para praticar a estruturação de páginas com HTML5 e sua estilização com CSS3. O repositório percorre conceitos fundamentais, navegação, organização de informações, recursos complementares e fundamentos de CSS, culminando em um projeto institucional completo.

## Demonstração online

Todos os exercícios estão publicados via GitHub Pages e podem ser visualizados diretamente no navegador, sem necessidade de download:

🔗 **[Acesse o projeto online](https://github.com/GilvamOliveira/HTML5-CSS3-Exercises-PROA)**

## Tecnologias

- HTML5
- CSS3
- JavaScript básico (exercícios pontuais e projeto final)

## Organização do repositório

Os exercícios estão distribuídos em cinco níveis de estudo, seguidos pelo projeto integrador:

- **Nível 1 — Primeiros passos com HTML:** estrutura básica, textos, citações, comentários e atributos.
- **Nível 2 — Links, imagens e navegação:** hyperlinks, galeria, portfólio, páginas internas e favicon.
- **Nível 3 — Organização de informações:** listas, tabelas, elementos block/inline, classes e IDs.
- **Nível 4 — Recursos complementares do HTML:** iframe e JavaScript integrado à página.
- **Nível 5 — Introdução ao CSS:** aplicação de estilos, sintaxe, seletores, cores, fundos e cards.
- **Projeto-Final:** site institucional da ONG fictícia Verde Vida.

## Como executar

Não há dependências, instalação ou servidor obrigatório. Há duas formas de visualizar as atividades:

**1. Online (recomendado)**

Acesse a versão publicada no GitHub Pages: [30-exercises-HTML5-CSS3-PROA](https://gilvamoliveira.github.io/30-exercises-HTML5-CSS3-PROA/)

**2. Localmente**

1. Abra a pasta do exercício desejado.
2. Abra o arquivo HTML indicado no README daquela pasta em um navegador moderno.
3. Quando houver mais de uma página, comece por `index.html`.

## Destaques de aprendizado

- Estrutura e semântica do HTML5
- Navegação com links e caminhos relativos
- Imagens, listas e tabelas
- CSS externo, interno e inline
- Seletores, cores, backgrounds, componentes e Flexbox
- Interações iniciais com JavaScript
- Organização de um site multipágina

## Projeto final

O diretório [Projeto-Final](Projeto-Final/) reúne o site da **ONG Verde Vida**, uma aplicação institucional com páginas de início, sobre e contato. Ele integra os principais recursos estudados ao longo da trilha.
