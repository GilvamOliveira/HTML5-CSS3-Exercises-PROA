# 70 Exercícios Práticos — HTML5 + CSS3

Coleção progressiva de exercícios de front-end desenvolvida para praticar a estruturação de páginas com HTML5 e sua estilização com CSS3. O repositório percorre conceitos fundamentais, navegação, organização de informações, recursos complementares, semântica, formulários, CSS intermediário e projetos integradores.

Esta versão amplia a coleção original de **30 exercícios** com mais **40 atividades**, totalizando **70 exercícios completos** no mesmo padrão de organização.

## Demonstração online

Todos os exercícios podem ser visualizados diretamente no navegador:

- **[Acesse o projeto online](https://gilvamoliveira.github.io/HTML5-CSS3-Exercises-PROA/)**

## Tecnologias

- HTML5
- CSS3
- JavaScript básico (exercícios pontuais e projeto final)

## Organização do repositório

Os exercícios estão distribuídos em onze níveis, sendo o último o projeto integrador final:

- **Nível 1 — Primeiros passos com HTML:** estrutura básica, textos, citações, comentários e atributos.
- **Nível 2 — Links, imagens e navegação:** hyperlinks, galeria, portfólio, páginas internas e favicon.
- **Nível 3 — Organização de informações:** listas, tabelas, elementos block/inline, DIV, classes, IDs e botões.
- **Nível 4 — Recursos complementares do HTML:** iframe e JavaScript integrado à página.
- **Nível 5 — Introdução ao CSS:** aplicação de estilos, sintaxe, seletores, cores, fundos e cards.
- **Nível 6 — Recursos e estrutura do documento:** botões, iframes, JavaScript, caminhos, HEAD, layout, responsividade e código.
- **Nível 7 — HTML semântico e boas práticas:** semântica, refatoração, entidades, símbolos, emojis, charset, URL encode e XHTML.
- **Nível 8 — Formulários, estrutura e campos:** primeiros formulários, cadastro, atributos, tipos de input, radios, checkboxes, selects, textarea, fieldset, datalist e datas.
- **Nível 9 — Formulários, validação e atributos:** number, range, color, file, search, atributos de input, validação, pattern e matrícula completa.
- **Nível 10 — CSS intermediário:** formas de aplicação, sintaxe, seletores, cores, comentários e modelo de caixa.
- **Nível 11 — Projeto Integrador:** página completa de inscrição em curso, integrando HTML, CSS e JavaScript.

## Como executar

Não há dependências, instalação ou servidor obrigatório. Há duas formas de visualizar as atividades:

**1. Online (recomendado)**

Acesse a versão publicada no GitHub Pages: [HTML5-CSS3-Exercises-PROA](https://gilvamoliveira.github.io/HTML5-CSS3-Exercises-PROA/)

**2. Localmente**

1. Abra a pasta do exercício desejado.
2. Abra o arquivo HTML indicado no README daquela pasta em um navegador moderno.
3. Quando houver mais de uma página, comece por `index.html`.

## Destaques de aprendizado

- Estrutura e semântica do HTML5
- Navegação com links e caminhos relativos
- Imagens, listas, tabelas e formulários
- CSS externo, interno e inline
- Seletores, cores, backgrounds, box model, componentes e layout
- Responsividade e acessibilidade
- Interações iniciais com JavaScript
- Organização de sites multipágina e projetos completos
