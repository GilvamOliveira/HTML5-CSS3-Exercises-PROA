Página inicial

Bem-vindo(a) ao meu pequeno site de exemplo, criado para praticar navegação entre páginas usando caminhos relativos.

Cada página compartilha o mesmo menu. Na página inicial, os links para as páginas internas começam com pages/; dentro da pasta pages/, os caminhos usam ../ para voltar ao arquivo principal e aos recursos.

Sobre Conheça a página interna e veja como os caminhos relativos funcionam. Contato Acesse os canais de contato do site de exemplo.

O mesmo arquivo assets/css/style.css é reutilizado pelas três páginas, mantendo a identidade visual do site.
