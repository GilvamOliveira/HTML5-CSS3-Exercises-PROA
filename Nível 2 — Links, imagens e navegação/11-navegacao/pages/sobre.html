Como os caminhos relativos funcionam

Como esta página está em pages/sobre.html, o link para a página inicial usa ../index.html: o ../ sobe um nível de pasta antes de abrir o arquivo.

O mesmo vale para os recursos:

  • ../assets/css/style.css carrega o CSS compartilhado;
  • ../assets/img/Logo site.jpg exibe a logo do site;
  • contato.html abre outra página da mesma pasta.

Manter a navegação e os caminhos consistentes evita links quebrados quando o site é aberto diretamente pelo sistema de arquivos.
