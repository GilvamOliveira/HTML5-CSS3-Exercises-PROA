# 09 — Galeria de Paisagens

## Sobre o exercício

Construir uma galeria simples de imagens acompanhadas por descrições alternativas.

## Tecnologias

- HTML5
- CSS3

## Estrutura

- `index.html` — página principal
- `assets/css/style.css` — folha de estilos
- `assets/img/favicon.svg` — ícone da página


## Conceitos praticados

Uso de `img`; caminhos relativos; textos `alt` descritivos; associação entre imagem e conteúdo.

## Como executar

1. Abra a pasta deste exercício.
2. Abra o arquivo HTML principal em um navegador moderno.
