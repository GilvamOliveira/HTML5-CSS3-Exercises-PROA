# 12 — Favicon e Título

## Sobre o exercício

Configurar informações do documento exibidas no navegador e úteis para mecanismos de busca.

## Tecnologias

- HTML5
- CSS3

## Estrutura

- `index.html` — página principal
- `assets/css/style.css` — folha de estilos
- `assets/img/favicon.svg` — ícone da página


## Conceitos praticados

`title`; `meta name="description"`; link de favicon; papel do `head` na configuração da página.

## Como executar

1. Abra a pasta deste exercício.
2. Abra o arquivo HTML principal em um navegador moderno.
