# 02 — Títulos

## Sobre o exercício

Demonstrar a hierarquia de títulos HTML e sua utilização para organizar conteúdo de forma semântica.

## Tecnologias

- HTML5
- CSS3

## Estrutura

- `index.html` — página principal
- `assets/css/style.css` — folha de estilos
- `assets/img/favicon.svg` — ícone da página


## Conceitos praticados

Hierarquia de `h1` a `h6`; uso de `hr`; listas; ênfase com `strong`; organização semântica do conteúdo.

## Como executar

1. Abra a pasta deste exercício.
2. Abra o arquivo HTML principal em um navegador moderno.
