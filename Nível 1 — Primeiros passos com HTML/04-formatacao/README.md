# 04 — Formatação de Textos

## Sobre o exercício

Explorar elementos HTML para dar significado e ênfase a trechos de texto.

## Tecnologias

- HTML5
- CSS3

## Estrutura

- `index.html` — página principal
- `assets/css/style.css` — folha de estilos
- `assets/img/favicon.svg` — ícone da página


## Conceitos praticados

`strong`, `em`, `mark`, `small`, `del`, `ins`, `sub` e `sup`; semântica de conteúdo textual.

## Como executar

1. Abra a pasta deste exercício.
2. Abra o arquivo HTML principal em um navegador moderno.
