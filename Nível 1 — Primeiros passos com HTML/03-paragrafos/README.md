# 03 — Parágrafos

## Sobre o exercício

Criar um texto informativo sobre tecnologia, aplicando a marcação adequada para blocos de texto.

## Tecnologias

- HTML5
- CSS3

## Estrutura

- `index.html` — página principal
- `assets/css/style.css` — folha de estilos
- `assets/img/favicon.svg` — ícone da página


## Conceitos praticados

Parágrafos com `p`; quebras de linha com `br`; separadores `hr`; títulos de seção; destaque com `strong`.

## Como executar

1. Abra a pasta deste exercício.
2. Abra o arquivo HTML principal em um navegador moderno.
