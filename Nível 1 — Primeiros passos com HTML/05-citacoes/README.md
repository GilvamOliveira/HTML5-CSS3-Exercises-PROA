# 05 — Citações

## Sobre o exercício

Apresentar frases famosas utilizando elementos apropriados para citações, abreviações e referências.

## Tecnologias

- HTML5
- CSS3

## Estrutura

- `index.html` — página principal
- `assets/css/style.css` — folha de estilos
- `assets/img/favicon.svg` — ícone da página


## Conceitos praticados

Citações curtas com `q`; citações em bloco com `blockquote`; autoria com `cite`; abreviações com `abbr`; rodapé semântico.

## Como executar

1. Abra a pasta deste exercício.
2. Abra o arquivo HTML principal em um navegador moderno.
