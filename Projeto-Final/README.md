# 30 — Projeto Final: ONG Verde Vida

## Sobre o exercício

Consolidar os fundamentos de HTML, CSS e JavaScript em um site institucional multipágina para uma ONG ambiental fictícia.

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Estrutura

`index.html` — página inicial com ações e indicadores
- `sobre.html` — história, missão e atuação
- `contato.html` — canais de contato e chamada à ação
- `assets/css/style.css` — estilos compartilhados
- `assets/img/` — logo, banners e favicon

## Conceitos praticados

Site multipágina; navegação; layout responsivo; seções e tabelas; imagens e favicon; CSS compartilhado; interações JavaScript; identidade visual consistente.

## Como executar

1. Abra a pasta deste exercício.
2. Abra o arquivo HTML principal em um navegador moderno.
3. Use o menu para navegar entre as páginas do site.
