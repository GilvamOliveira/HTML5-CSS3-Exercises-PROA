# 59 — Number e Range

## Sobre o exercício

Use campos numéricos e controles deslizantes para limitar valores e facilitar a escolha dentro de uma faixa.

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Estrutura

- `index.html` — página principal
- `assets/css/style.css` — folha de estilos
- `assets/img/favicon.svg` — ícone da página
- `script.js` — atualiza o valor exibido pelo controle deslizante


## Conceitos praticados

`type="number"`; `type="range"`; `min`, `max` e `step`; `inputmode`; `output`; atualização de valor com JavaScript; usabilidade.

## Como executar

1. Abra a pasta deste exercício.
2. Abra o arquivo `index.html` em um navegador moderno.
