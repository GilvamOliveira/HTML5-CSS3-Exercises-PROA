# 65 — Input Form Attributes

## Sobre o exercício

Controle o envio de um formulário com formaction, formmethod, formnovalidate, formtarget e o atributo form.

## Tecnologias

- HTML5
- CSS3

## Estrutura

- `index.html` — página principal
- `assets/css/style.css` — folha de estilos
- `assets/img/favicon.svg` — ícone da página

## Conceitos praticados

`formaction`; `formmethod`; `formenctype`; `formnovalidate`; `formtarget`; atributo `form` para associar controles externos ao formulário; diferentes ações por botão.

## Como executar

1. Abra a pasta deste exercício.
2. Abra o arquivo `index.html` em um navegador moderno.
