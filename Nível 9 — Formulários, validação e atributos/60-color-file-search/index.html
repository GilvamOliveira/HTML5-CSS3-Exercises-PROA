Color, File e Search

Cada tipo de campo possui comportamentos e atributos próprios que melhoram a experiência de preenchimento.

Personalização do perfil

O navegador abre um seletor de cores nativo.

Aceita arquivos PNG, JPEG ou WebP.

Use Ctrl ou Command para selecionar mais de um arquivo.

Atributos dos arquivos

  • accept define os formatos sugeridos ou aceitos.
  • multiple permite selecionar vários arquivos.
  • capture pode abrir a câmera em dispositivos compatíveis.
  • O envio de arquivos exige enctype="multipart/form-data" no formulário.

Importante: a validação do tipo de arquivo no navegador é apenas uma ajuda. O servidor também precisa validar extensão, tamanho e conteúdo.
