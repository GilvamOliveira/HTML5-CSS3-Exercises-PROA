# 60 — Color, File e Search

## Sobre o exercício

Pratique campos de seleção de cor, envio de arquivos e busca com interfaces nativas e atributos específicos.

## Tecnologias

- HTML5
- CSS3

## Estrutura

- `index.html` — página principal
- `assets/css/style.css` — folha de estilos
- `assets/img/favicon.svg` — ícone da página


## Conceitos praticados

`type="color"`; `type="file"`; `type="search"`; `accept`; `multiple`; `capture`; estilização de botões de arquivo; experiência do usuário.

## Como executar

1. Abra a pasta deste exercício.
2. Abra o arquivo `index.html` em um navegador moderno.
