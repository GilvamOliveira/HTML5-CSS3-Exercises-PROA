# 64 — Pattern

## Sobre o exercício

Use expressões regulares no atributo pattern para validar formatos específicos diretamente no navegador.

## Tecnologias

- HTML5
- CSS3

## Estrutura

- `index.html` — página principal
- `assets/css/style.css` — folha de estilos
- `assets/img/favicon.svg` — ícone da página


## Conceitos praticados

Atributo `pattern`; expressões regulares; validação de formato; `title` como orientação; limites do pattern; validação no servidor.

## Como executar

1. Abra a pasta deste exercício.
2. Abra o arquivo `index.html` em um navegador moderno.
